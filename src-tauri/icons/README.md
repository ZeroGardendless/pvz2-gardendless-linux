# Application artwork

Gardendless.png is the Gardendless artwork from the official website:
https://github.com/Gzh0821/pvzg_site/blob/main/src/.vuepress/public/pvz_logo-round.webp

Desktop icon sizes were generated with the Tauri icon command. These replace
the Tauri template mark. The artwork remains part of the game assets; this
project does not claim a new license for it.
