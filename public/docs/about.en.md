## FAQ

### The game shows a white screen on startup. What should I do?

This is a device-specific issue. Try "Local Download" from the official website.

### Where is Sandbox Level?

Sandbox Levels are in the GitHub Level Window. Here is an explanation of what each button does in Sandbox Levels:

**Sandbox Level Hotkeys (click the purple "i" button)**

| Action | Key |
| --- | --- |
| Switch stage effect | <kbd>Tab</kbd> |
| (Full) Tide in | <kbd>Backspace</kbd> |
| (Full) Tide out | <kbd>Enter</kbd> |
| Tide in/out by one square | <kbd>←</kbd> / <kbd>→</kbd> |
| Switch cards (hover over card) | Mouse wheel |
| Freeze time | <kbd>F5</kbd> |
| Spawn random zombies | <kbd>F1</kbd> |
| Switch lawn | <kbd>F2</kbd> |

- <span class="tip">Free plant</span>: free plants
- <span class="tip">Cooldown Off</span>: no planting cooldown
- <span class="tip">Free plant food</span>: free plant food

The arrow next to the "i" button controls the zombie spawn style.

**Common Hotkeys:**

- Press <kbd>A</kbd> during gameplay to collect sun, coins, and diamonds
- Right-click a plant at the right moment to play its watering animation
- Middle-click a plant to trigger its plant food effect
- Use the keyboard to auto-match empty Banana Launchers or Missile Toes: <kbd>B</kbd>
- Press <kbd>~</kbd> to hide UI

### Why did all the UI disappear?

Press <kbd>~</kbd> to hide UI. Please check whether you accidentally pressed this key.

<span class="warning">If that doesn't work, it cannot be fixed.</span>

### Do I need to re-download the game every update? Will my player datas be kept?

If the downloaded version has exactly the same file format, progress will be inherited.

If the old version was a single exe file but the new version is a folder containing an exe, progress <span class="warning">will not</span> be inherited.

### How do I edit my player datas?

Go to the Player Selector Window on the main menu.

You can export your current player data and edit it.

Import it back to add it as a new player profile.

### How do I unlock plants that are still locked in the Almanac?

Keep playing.

### Why are all the zombies question marks in the Almanac?

Zombies appear in the Almanac only after you encounter them.

You must win the level where the zombie appears to fully unlock its Almanac entry.

<span class="warning">Sandbox Levels cannot be won.</span>

### Worlds other than Egypt are locked. How do I unlock them?

<span class="tip">World Keys.</span>

Each world has a "Gargantuar" level, which are specifically decorated.

### Why is the main line levels very hard after the first Zomboss fight?

The levels after the first Zomboss fight are expansion levels, not included by the main line.

Expansion levels are designed around the strength of plants from other worlds, so the difficulty spikes.
