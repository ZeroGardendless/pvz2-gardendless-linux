## 常见问题（FAQ）

### 启动的时候卡白屏怎么办？

设备原因，可尝试官网“本地下载”版本。

### 沙盒模式在哪里？

GitHub关卡窗口中由“沙盒”关卡。对于沙盒模式各个按钮的作用，下面给出解释：

**沙盒模式快捷键功能翻译（点击紫色“i”键）**

| 功能 | 按键 |
| --- | --- |
| 切换舞台效果 | <kbd>Tab</kbd> |
| （完全）涨潮 | <kbd>Backspace</kbd> |
| （完全）退潮 | <kbd>Enter</kbd> |
| 涨潮或退潮一格 | <kbd>←</kbd> / <kbd>→</kbd> |
| 切换卡牌（鼠标放在卡牌上） | 鼠标滚轮 |
| 时间冻结 | <kbd>F5</kbd> |
| 生成随机僵尸 | <kbd>F1</kbd> |
| 切换草坪 | <kbd>F2</kbd> |

- <span class="tip">Free plant</span>：植物不耗费阳光
- <span class="tip">Cooldown Off</span>：种植无冷却
- <span class="tip">Free plant food</span>：免费叶绿素

在“i”按键边上的箭头则是控制僵尸出场方式。

**普通模式快捷键：**

- 游戏进行时，按 <kbd>A</kbd> 键可以收集阳光、金币和钻石
- 对场上的植物在适当的时机右键，可以播放浇水动画
- 对场上的植物中键，可以触发叶绿素效果
- 使用键盘可以自动匹配场上空余的香蕉炮或槲寄冰仙子：香蕉炮是 <kbd>B</kbd> 键，冰仙子是 <kbd>N</kbd> 键
- 按下 <kbd>~</kbd> 可以隐藏 UI

### 为什么所有的 UI 都不见了？

按下 <kbd>~</kbd> 键可以隐藏 UI，请您检查是否是误按此按键致使 UI 被隐藏。

<span class="warning">如果无效，则无法解决。</span>

### 每次更新游戏时都需要重新下载新版本，我的存档还在吗？

假如下载的版本文件格式完全一致，则会继承原进度。

如果旧版本是单独的 exe 文件，但是新版本是一大堆文件包含一个 exe 文件，则<span class="warning">不会继承</span>。

### 如何修改存档？

在主界面的用户选择界面。

可以导出现有存档，并编辑。

编辑完毕再导入即可作为新玩家数据进入列表。

### 植物图鉴中未解锁的植物如何获得？

坚持游玩。

### 为什么僵尸图鉴中都是问号？

僵尸需要遇到才会出现在图鉴中。

僵尸所在的关卡必须胜利才能完全解锁其图鉴。

<span class="warning">沙盒模式无法胜利。</span>

### 除了埃及以外的世界都被锁着，如何解锁其他的世界？

<span class="tip">时空钥匙。</span>

每个世界都有“巨尸”关卡，浮岛特征明显。

### 为什么主线很难通关（指第一次击败僵尸博士之后）？

第一次打败之后的不是主线而是拓展关卡。

拓展关卡根据玩家获取了其他世界的植物的强度设计，难度飙升。
