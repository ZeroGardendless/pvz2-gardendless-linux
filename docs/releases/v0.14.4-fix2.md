# v0.14.4-fix2

Hey! This update focuses on smoother levels and a GP-Next that's easier to use and maintain.

The main fix is for the severe FPS drop that could show up after playing for a while. On Linux, sound effects were putting too much pressure on WebKitGTK's audio pipelines. They now reuse a small set of players even when the sound changes, and the game clears those players if audio activity accompanies a sustained frame stall. Failed sounds also clean up immediately. Music and sound effects stay audible.

GP-Next has had a larger cleanup since the last release:

- The overlay now lives in readable, organized modules instead of the old generated JS chunks. Its tabs, settings, search, logs and About page have been refreshed.
- Tools now includes a UUID generator, mod troubleshooting, preference export/import and a recovery mode for bad mod startups.
- FPS limits work from 30 to 240, with 120 as the default. The Performance tab does less work while collecting frame history.
- Widescreen styles can be set to None, Fog or Bushes, with artwork appearing only when the visible game window is wider than 1920 pixels.
- On first launch, Linux chooses a suitable GPU and avoids the NVIDIA DMA-BUF path when it would cause trouble. Tiling window managers hide the native titlebar; other desktops keep it.

Windows build support has also been prepared, but the Windows executable still needs testing on an actual Windows PC. This release includes the standalone Linux binary; there is no AppImage to install.

Thanks for sticking with the audio fixes. If you find another slowdown, the GP-Next Logs tab can export diagnostics that will help track it down.

— Zero
