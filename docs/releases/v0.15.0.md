# v0.15.0

Hey! This release adds the Gardendless Launcher and brings the game, GP-Next, and player tools together in one place.

The executable now opens a launcher with a Library for the included game, imported installations, save profiles, and launch controls. `--game` still starts the bundled game directly. The interface has a responsive Material 3 layout, locally bundled Google Sans Flex, light and dark themes, color palettes, and optional Caelestia/Quickshell color syncing on Linux. Controls have clearer feedback and respect reduced-motion settings.

The launcher can:

- Browse GitHub releases and their notes, cache them for offline reading, and download compatible game builds. Downloads are staged and checked against GitHub's published size and SHA-256 digest before installation. Existing versions stay available for rollback.
- Keep new profiles in separate save and GP-Next storage, while the default profile continues using your existing data. Choose a Linux GPU per profile or let automatic selection prefer a suitable AMD or integrated device. Windows GPU preference remains in Windows Graphics settings.
- Set GP-Next launch preferences for frame rate, widescreen style, experiments, and audio preset. Its workspace shows the selected profile's packages before launch, links to the save and keybind editors, and provides shortcuts to the official tools and documentation.
- Edit saves on Linux directly from the selected profile's WebKit database. The editor covers players, currencies, plants and costumes, worlds, endless levels, upgrades, and progression. Plant cards can be switched individually or unlocked together. Edits remain a draft until Apply, and each write makes a restorable backup. Windows currently supports JSON import, editing, and export rather than direct database access.
- Edit all 57 bundled keybind actions with search, key recording, reset controls, and shared-binding hints. Session logs and an audio-runtime check help with troubleshooting.

The Linux audio path now offers Performance, Balanced, and Rich presets. It reuses sound-effect players, limits pending work, and responds to sustained stalls without leaving effects muted for several seconds. Music streams without decoding whole tracks into Web Audio first. These are practical mitigations for WebKitGTK/GStreamer behavior, not a promise that every sound on every machine will play perfectly.

There are three downloads below: a standalone Linux x64 binary, a Flatpak bundle, and a Windows x64 test package. The Flatpak uses a consistent GNOME/WebKitGTK/GStreamer runtime and stores its saves separately from the native build. It needs the GNOME runtime on the destination PC; it is not a Flathub update feed. For Windows, extract the ZIP and keep `gardendless.exe` beside `WebView2Loader.dll`; install the Microsoft Edge WebView2 Runtime if it is missing. The Windows build was cross-compiled on Linux and has not yet been tested on a Windows PC.

If a particular level or sound still causes trouble, please share a GP-Next Performance sample and the launcher session log. Those reports make the next fix much easier to pin down.
