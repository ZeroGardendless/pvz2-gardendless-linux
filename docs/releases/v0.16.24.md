# v0.16.24

Hey! This updates the game to Gardendless 0.16.24, keeps our GP-Next improvements, and brings a much more useful render exporter alongside the first measured Aurum rendering improvements.

## Game and GP-Next

- Updated the game to the official Gardendless 0.16.24 content and integrated GP-Next 1.5.11's mod-loading and startup architecture.
- Restored the normal release's PNG textures instead of Lite's AVIF/WebP assets. All 622 PNGs were checked against the full release and have identical decoded pixels. File-size reductions use lossless compression.
- Kept our familiar overlay, launcher, Linux audio backend, GPU preferences, widescreen controls and save handling.
- Added stable per-build asset URLs so cached Lite metadata or textures cannot hide replacement assets. Saves and preferences are preserved.
- Restored the native package commands used by the updated mod loader, including installed-pack reads and local package inspection. Package installation remains validated and staged before activation.

## Game windows and UI

- Updated the HTML game windows alongside the new game contents: properly rendered Markdown about/update pages, key binding edits, community levels and music-pack ordering.
- Community-level and update requests now use a bounded Tauri transport on desktop. External links use the existing native opener.
- Music-pack folder imports use the native directory picker and read only files declared by the selected pack. New imports store audio as typed arrays, fixing a reproduced WebKit stall when writing audio Blobs to IndexedDB; existing packs remain readable.
- Removed zero-opacity entrance animations that could make menus disappear and return. Preserved existing launcher content during unchanged background refreshes.
- GP-Next dropdowns now use HTML controls instead of native popups. Tab-overflow menus keep their items during unchanged layout refreshes.
- Closed GP-Next panels and drawers are fully hidden and noninteractive. The shortcut hint remains available.

## Character and misc renders

- Added a launcher render exporter and custom preview tool using the game's actual skeletons, atlases, sprite frames and attachment sockets.
- Added plants, zombies and a separate Misc section, including projectiles, armour, scenery, tiles and visual references from resource containers.
- PNGs are organized by codename, costume, appearance state, action and animation position. Every export includes a manifest with its sources and any skipped or unsupported entries.
- Added selectable output detail, with 4× as the default. Large images are limited to 4096 pixels per side and their actual scale is recorded.
- Added action poses rather than only idle images: shooting, eating, plant-food animations, damage, transformations and other named clips are sampled at the start, middle and near the end. Idle poses remain at frame zero.
- Added plant costumes, powered shadow appearances, persistent defensive-plant armour and its damage stages, and Lychee's normal/plant-food shell stages.
- Fixed Umbrella Leaf's missing upper leaves, missing starting armour, exposed severed-arm stubs on healthy zombies, and temporary butter appearing as a separate character.
- Separated Yeti's world costumes and damage layers. Fixed the helmet fragment appearing on normal Abbot renders while keeping it on the helmet variant.
- Custom previews support appearance states, animation position, output detail, zombie armour and supported butter/poison-face visuals.

## Aurum

- Bundled Aurum 0.5.0-alpha with configurable draw culling. Fully offscreen skeletal meshes, and meshes completely covered by an opaque HTML window, can skip draw submission. Bone updates, game logic, animation events and audio continue running.
- Culling checks current posed mesh vertices, camera/layer visibility and verified shader implementations. Partial coverage, translucent windows and unsupported/custom rendering keep their draw path.
- Real Cocos/WebKit pixel comparisons passed for centered, edge-crossing, mirrored and offscreen meshes with both the built-in and game colour shaders. Closing an opaque window restored the same pixels. This is correctness evidence, not a new FPS benchmark.
- Upstream 0.16.24 changes character-logic scheduling. Its rectangle collision functions match 0.16.15; Aurum retains the guarded broad phase without replacing that scheduling.

- Added a per-profile Aurum control beside Play, with the existing package review and update workflow.
- Added guarded rejection of distant collision pairs and bounded reuse of parsed object references. Live game objects and result arrays are not cached.
- Added compatible skeletal batching and a short startup cover fade. Optional speculative prefetch remains off by default.
- Reduced redundant zombie shader-buffer uploads and unchanged white-tint work. Active visual effects and unsupported/custom implementations retain the original update path.
- In the earlier 0.16.15 headless Modern Day 16 test at 1920×1080 with 100 added zombies, the median CPU frame duration across three comparisons fell from 30.8 ms to 20.2 ms. Gains varied with active effects; this is not a promised FPS improvement on every GPU or level.
- Added short CPU frame/hotspot samples and memory/optimization counters for further profiling. These measurements run only when requested.

## Audio and memory

- Extended metadata-only preloading to the full release's MP3 resources as well as Lite M4A. Unused preload requests no longer need to decode their PCM immediately.
- Verified headers for all 3,493 bundled MP3 resources without decoding PCM. Header probes are limited to four concurrent requests to avoid startup bursts.
- Kept deferred first-play preparation, clip reuse, bounded decoded-audio caching and cancellation handling. The decoded cache budget is 96 MiB; live voices are separate from that budget.
- No sounds, animation ticks or gameplay updates are deliberately removed by the new visual optimization.

## Notes

- Restart the launcher and apply **Aurum → Update** to install the bundled mod changes, then launch the game again. Updating the Flatpak alone does not silently replace an already-installed Aurum package.
- Exports reproduce authored skeleton/sprite poses and supported appearance recipes. Effects that require a live gameplay simulation are not automatically recreated; the manifest reports unsupported assets and empty poses.
- Native GP-Next cloud-save authorization remains unavailable. Account features continue to open the official website.
- Gardenest storage-host download failures remain a known issue.
- Source checks, isolated native startup/audio tests and renderer checks are separate from physical-GPU, audible-playback and gameplay acceptance. A one-second cold start has not been achieved.
